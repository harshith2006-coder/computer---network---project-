# 🛡️ URL Safety Analyzer

A Chrome Extension and FastAPI-powered security tool that analyzes URLs in real time to detect phishing attacks, malicious links, suspicious redirects, and affiliate hijacking attempts.

## Features
- SSL Validation
- DNS Analysis
- WHOIS Lookup
- Redirect Tracking
- Risk Scoring
- Phishing Detection
- Affiliate Link Detection

## Tech Stack
- Python
- FastAPI
- JavaScript
- Chrome Extension API
